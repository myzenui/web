# Benim Sitem Web Sitesi

Bu depo, apartman ve site yönetim yazılımı **Benim Sitem** için tanıtım amaçlı hazırlanmış bir web sitesini içerir.

## Özellikler
- Aidat, ısınma, su gibi tüketim takibi
- Mesajlaşma ve push bildirim/SMS gönderme
- Araç takibi
- Google Sheets entegrasyonu ile Excel kurmadan yönetim
- iOS ve Android uygulamaları

## Sayfa Özellikleri
- Font Awesome ikonları ve görseller
- CSS animasyonları ile zenginleştirilmiş arayüz
- Navigasyon menüsü ve her özellik için kaydırmalı detay bölümleri

## Kullanım
`index.html` dosyasını bir tarayıcıda açarak tanıtım sitesini görüntüleyebilirsiniz.
